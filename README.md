# 我的小宇宙 · A Collection of Worlds

Two independent authored worlds: the accepted Paper Garden and CROSSOVER 02, a monochrome paper/foil/type/cable concept sculpture.

Collection: https://jialepang392-web.github.io/my-little-orbit/?v=060

Paper Garden: https://jialepang392-web.github.io/my-little-orbit/poem.html?v=060

CROSSOVER 02: https://jialepang392-web.github.io/my-little-orbit/crossover.html?v=060

Current version: 0.6.0. Three.js r180, static HTML/CSS/ES modules. No API keys required.
The new concept is based on the user-supplied monochrome collage reference. Artwork and texture maps are programmatically authored; no image-generation service was invoked. Its working Chinese title is 错频.
The homepage loads only static covers, not multiple WebGL scenes. Forest previews and downloads are archived outside the current public build; previous Git history has not been rewritten.

Third-party notices and Three.js MIT license are retained. The title SVG contains only seven laid-out character outlines; no font file is distributed.
