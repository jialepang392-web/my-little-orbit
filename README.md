# 思念若是一首诗 · Paper Garden

An explorable personal blog in a spherical paper, celadon and botanical assemblage.

Live: https://jialepang392-web.github.io/my-little-orbit/?v=050

Reference and real browser screenshots: https://jialepang392-web.github.io/my-little-orbit/art-review.html?v=050

Current version: 0.5.0. Three.js r180, static HTML/CSS/ES modules. No API keys required.
Generated concept references are explicitly labelled; the interactive scene uses actual geometry, not an image masquerading as a 3D globe. Older Blender downloads are historical v0.3 assets.

Third-party notices and Three.js MIT license are retained. The title SVG contains only seven laid-out character outlines; no font file is distributed.
