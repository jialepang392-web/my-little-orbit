# 我的小宇宙 · A Collection of Worlds

Two independent authored worlds: the accepted Paper Garden and 删了一百遍 / DELETED A HUNDRED TIMES, a monochrome paper/foil/type/cable concept sculpture.

Collection: https://jialepang392-web.github.io/my-little-orbit/?v=061

Paper Garden: https://jialepang392-web.github.io/my-little-orbit/poem.html?v=061

Deleted a Hundred Times: https://jialepang392-web.github.io/my-little-orbit/crossover.html?v=061

Current version: 0.6.1. Three.js r180, static HTML/CSS/ES modules. No API keys required.
The concept is based on the user-supplied monochrome collage reference, with the user-confirmed title 删了一百遍. Artwork and texture maps are programmatically authored; no image-generation service was invoked. The download includes actual normal-mapped foil, layered print and the title in its scene metadata.
The homepage loads only static covers, not multiple WebGL scenes. Forest previews and downloads are archived outside the current public build; previous Git history has not been rewritten.

Third-party notices and Three.js MIT license are retained. Each title SVG contains only its laid-out character outlines; no font file is distributed.
